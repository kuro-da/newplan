# newplan — AIエージェント事業 (目標: 月200万円 / 初期投資2万円)

## 結論(正直な前提)
- AIが自律的に200万円/月を稼ぐことは保証できない。収益の源泉は「顧客への営業と信頼」で、AIはそれを安く・速くする道具。
- 現実的な式: **月額10万円 × 20社 = 月200万円**(または5万円 × 40社)。
- したがって事業の中身は「AIエージェントによる業務代行サブスク」。

## 商品案(最初の1つに絞る)
中小企業の定型事務をAIで代行し、月額定額で提供する。
1. 請求書・発注の突合チェック(既に invoice-checker の原型あり)
2. 売上/入金の照合・月次レポート自動作成
3. 問い合わせメール一次対応の下書き

→ まず **1** を商品化。自社(media-b)で実運用した実績を営業材料にする。

## 2万円の予算配分
| 項目 | 金額 |
|---|---|
| Claude API 利用料(検証・初期顧客分) | 8,000円 |

## 90日ロードマップ
- 0-2週: 自社データで実績数値を作る(削減時間、検出した差異件数)。LP作成。
- 3-6週: 知人・取引先10社に無料トライアル。3社を有料化(月3-5万円)。
- 7-12週: 事例を元に営業。目標 有料8社 / 月40万円。
- 以降: 10万円プランへ単価アップ + 紹介。200万円到達の目安は6-12か月。

## 前提・リスク
- 顧客の請求書など機密データを扱うため、契約・情報管理の整備が必須。
- 月200万円は到達保証ではなく目標。3か月で有料5社に届かなければ商品か営業先を見直す。

## 事業の条件(2026-10-09 社長より)
**社会課題を解決する、もしくは人の役に立つ事業であること。**

- 本事業の位置づけ: 地方の中小企業は経理が兼任・少人数で、月末の確認作業の負担と、請求ミスの見落としが課題。その負担と不安を減らし、人が本来の仕事に時間を使えるようにする。AIは人の仕事を奪うためでなく、人が安心して判断するために使う。
- 正直な評価: 「人の役に立つ」実務型の事業。強い社会課題の解決(福祉・環境・地域再生など)とは言えない。
- 判断のものさし: 顧客が実際に時間・お金・不安を減らせたか(トライアルで測る)。減らせなければ、事業を見直す。
- 山梨の地域再生に近づけたい場合の方向: 地元の小規模事業者・福祉事業所・NPOには料金を下げる枠を設ける。社長が望めば検討する。

## 進め方と回収方法(2026-10-09 社長より)
- **取引先への営業は一番最後。** それまでに、商品・サイト・書類・決済を整える。
- **回収は「銀行振込」か「ネット決済(カード)」。**
  - 銀行振込: 月末締め・翌月末払い。請求書を発行する。最初はこれで始められる(口座は既存の会社口座を使う)。
  - ネット決済: 決済サービス(Stripe・Square など)の契約が必要。申込と本人確認は社長が行う(私は口座開設・決済情報の入力はしない)。
- **社長の決裁待ちで止めない。** 下書き・準備は先に進める。ただし次は社長の操作が必要: 外部への送信、サイトの公開、決済サービス・口座の契約、規約への同意。
- 準備した書類(下書き): 特定商取引法に基づく表記、利用規約、プライバシーポリシー(`site/`)。公開前に専門家の確認を推奨。
