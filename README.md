# newplan — AIエージェント事業 (目標: 月200万円 / 初期投資2万円)

## 結論(正直な前提)
- AIが自律的に200万円/月を稼ぐことは保証できない。収益の源泉は「顧客への営業と信頼」で、AIはそれを安く・速くする道具。
- 現実的な式: **月額10万円 × 20社 = 月200万円**(または5万円 × 40社)。
- したがって事業の中身は「AIエージェントによる業務代行サブスク」。

## 商品案(最初の1つに絞る)
中小企業の定型事務をAIで代行し、月額定額で提供する。
1. 請求書・発注の突合チェック(既に invoice-checker の原型あり)
2. 売上/入金の照合・月次レポート自動作成
3. 問い合わせメール一次対応の下書き

→ まず **1** を商品化。自社(media-b)で実運用した実績を営業材料にする。

## 2万円の予算配分
| 項目 | 金額 |
|---|---|
| Claude API 利用料(検証・初期顧客分) | 8,000円 |
| ドメイン + LP公開(無料ホスティング) | 2,000円 |
| 営業(DM/広告テスト) | 8,000円 |
| 予備 | 2,000円 |

## 90日ロードマップ
- 0-2週: 自社データで実績数値を作る(削減時間、検出した差異件数)。LP作成。
- 3-6週: 知人・取引先10社に無料トライアル。3社を有料化(月3-5万円)。
- 7-12週: 事例を元に営業。目標 有料8社 / 月40万円。
- 以降: 10万円プランへ単価アップ + 紹介。200万円到達の目安は6-12か月。

## 前提・リスク
- 顧客の請求書など機密データを扱うため、契約・情報管理の整備が必須。
- 月200万円は到達保証ではなく目標。3か月で有料5社に届かなければ商品か営業先を見直す。

## 次に社長が決めること
1. 最初の商品(上記1〜3のどれか)
2. 営業先の業種(例: 山梨の中小製造/小売)
3. 週に使える営業時間

## 決定事項(2026-10-09 Claudeが一任を受けて決定)
1. **最初の商品: 請求書・発注の突合チェック。** 既存の `invoice-checker`(切り捨て・1円差も差異として検出)が原型。自社実績を営業材料にできる。
2. **営業先: 山梨県内の従業員10〜50人の製造・卸・建設資材・小売。** 月の請求書が多く、経理が兼任で、1円差の確認に時間を取られやすい層。
3. **社長の営業時間: 週2時間(商談のみ)。** リスト作成・文面作成・資料作成・フォロー文は私が下書きまで担当。

## 「すべて自動」の範囲と線引き
- 自動でやる: 見込み客リスト案、DM/メール文面、LP文、デモ資料、商談後フォロー文の作成。
- 社長の承認が必要: 外部への送信、契約、請求、顧客データの取り扱い。法的・信用上の責任が社長に及ぶため、完全自動送信はしない。
