# 見込み客リストの作り方(山梨・従業員10〜50人の製造/卸/建設資材/小売)

## 方針
- 社名・規模は、**公開されている一次情報で確認できたものだけ**をリストに入れる(推測で書かない)。
- 最優先は **メディアビーの既存の取引先・知人の会社**。信頼があり、無料トライアルの承諾率が最も高い。
- 次に、地域の団体名簿・公開DBから探す。

## 情報源(確認済みの存在)
- 山梨県の企業名簿・県の公開資料: https://www.pref.yamanashi.jp/
- 各商工会議所・商工会の会員名簿(甲府・山梨・富士吉田 等)
- 国税庁 法人番号公表サイト(所在地・商号の確認。従業員数は無い)
- SalesNow 山梨県の会社一覧(従業員数で絞れる。連絡先付きは有料): https://salesnow.jp/db/prefectures/yamanashi
- 業界団体の会員名簿(例: 建材・機械・卸の協同組合)

## 記録シート(prospects.csv に1社1行)
列: 社名 / 所在地 / 業種 / 従業員数(出典) / 情報源URL / 取引先か(はい/いいえ) / 連絡先(公開されているもの) / 状態 / 備考

状態の値: 未連絡 → 承認待ち → 送信済 → 返信あり → 商談 → トライアル → 有料 → 見送り

## ルール
- 送信前に必ず社長が文面と宛先を確認(自動送信しない)。
- 個人名・個人メール等の個人情報は集めない。会社の代表窓口(公開のメール/フォーム)のみ。
- 営業メールは、特定電子メール法の表示義務(送信者名・連絡先・配信停止の方法)を満たす。
- 反応がなかった先へのフォローは1回まで。
